# Pharmacy Daily Accounting & Sales Management Web App + PWA

## Project Overview
A production-ready bilingual (English / বাংলা) pharmacy accounting web app with a 4-digit
PIN lock on startup, Firebase Firestore sync, offline medicine autocomplete, smart quick
entry parsing, Telegram bot webhook, and automated daily backup to Gmail + Google Drive.
Configured for Android APK export via Capacitor.

## Tech Stack
- **Frontend:** React 18 + Vite + Tailwind CSS + Lucide React + VitePWA
- **Mobile:** Capacitor (`@capacitor/core`, `@capacitor/android`) for APK build
- **Backend:** Firebase Firestore (client SDK) + Node.js serverless functions (Telegram webhook, backups)
- **Storage:** LocalStorage/IndexedDB cache for offline medicine autocomplete
- **Automation:** Nodemailer (Gmail) + Google Drive API (backup)

## Build & Run Commands
```bash
npm install
npm run dev            # Vite dev server
npm run build          # production build
npx cap init          # (once) add Capacitor
npx cap add android
npx cap run android   # build + run APK on device/emulator
```

## Credential Setup (`.env`)
See `README.md` and `.env.example`. Required:
- `VITE_FIREBASE_*` — Firebase config (client-safe)
- `TELEGRAM_BOT_TOKEN` — BotFather token
- `GOOGLE_APPLICATION_CREDENTIALS` — service account JSON path (Drive + Gmail)
- `DRIVE_FOLDER_ID` — target Drive folder for backups
- `OWNER_GMAIL` — daily report recipient

## Key Conventions
- All monetary values stored as integers in BDT (smallest unit = taka).
- Firestore collections: `sales`, `dues`, `expenses`, `settings`, `custom_medicines`.
- All UI strings live in `src/data/translations.js` under `en` / `bn` keys.
- Date filter uses local Asia/Dhaka timezone.
